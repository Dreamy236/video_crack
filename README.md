# VideoLinkCollector —— 多平台视频链接采集与下载工具

> 一个本地优先（local-first）的桌面端工具：把抖音 / 快手 / B站 / 小红书 / 微博 / YouTube 等平台的视频链接，**解析为无水印直链并批量下载**，同时支持「按作者 + 关键词」组合检索、播放列表展开、画质/编码定制、结果导出。
>
> 架构：**Python 零依赖后端（`http.server` + yt-dlp）+ 原生 JS 前端**，可源码运行，也可 exe 文件双击即用。

---

## 一、功能一览

### 1. 四大功能页签（前端顶部 Tab）

| 页签 | 作用 |
|---|---|
| 🔎 **链接检索** | 粘贴视频/作者链接，做「关键词搜索」或「列表解析」，结果带封面、作者、点赞、时长，可排序/筛选/导出 |
| ⬇️ **yt-dlp 下载** | 单条视频解析全部画质、选轨下载；含「批量下载（列表/播放列表）」区 |
| 🔑 **Cookie 管理** | 各平台网页内登录，保存登录态（解锁抖音下载、提升检索成功率） |
| 📂 **下载列表** | 已下载历史、进度、去重提示、重新打开/定位文件 |

### 2. 链接检索（Search）

- **关键词搜索**：跨 6 个平台通用「真实浏览器通道」（Playwright 驱动 Chromium），自动绕过签名风控；B站/快手/微博另走 HTTP 直连通道。
- **作者 + 关键词组合搜索（B站）**：同时输入 UP 主名/UID 和关键词，由 B站服务端做**全量投稿过滤分页**（非仅扫最新 150 条），召回更全。
- **B站歌单/合集自动识别**：粘贴合集 / 收藏夹 / 番剧 / 分P 链接，自动展开为每条视频单独解析。
- **结果增强**：可勾选「Bilibili 补充详情（时长/点赞）」、`enrich` 补全元信息。
- **结果后处理**：按平台/最低点赞/关键词筛选，按标题/点赞/时长排序；一键导出 **Markdown / CSV / TXT**，或复制为链接清单。

### 3. 下载（Download）

- **单条下载**：解析全部画质与音轨，支持「最高画质 / 1080p / 720p / 360p / 仅音频(MP3)」预设，及 H.264 / HEVC / AV1 / VP9 编码选择。
- **批量下载（列表 / 播放列表）**：
  - 粘贴播放列表链接或多条链接（空格/换行/逗号分隔，也可直接粘贴检索导出的 `links.txt`）。
  - B站播放列表自动展开为每条视频；多选后统一设置格式批量下载。
  - 全局格式/编码 + 「直接按全局格式下载（跳过逐条设置）」一键批量。
  - 合并容器可选 mp4/mkv/webm/mov/flv/avi；支持自定义格式编号（如 `137+140`）。
- **抖音浏览器直连**：解析播放器自身签名的真实直链（无水印），无需经 yt-dlp 选轨。

### 4. 无水印能力

- **抖音无水印**：直连通道优先取 `play_addr_h264` / `bit_rate` 无水印源，并对带水印源做 `watermark=1→0`、`/playwm/→/play/` 改写兜底（已单元测试 + 真实抽帧视觉验证通过）。
- **B站去水印（实验）**：可选 ffmpeg `delogo` 裁剪右下角 UID 角标（仅对静态角标有效，非 B站链接不受影响）。
- **作者名修正**：抖音列表解析优先展示真实昵称（如「自然-」）而非 handle（如 `Ashley_hh_`）。

### 5. 其他

- **去重下载**：已下载地址自动跳过，提示前往下载列表查看。
- **主题切换**：跟随系统 / 明亮 / 暗色。
- **跨平台一致接口**：6 个平台统一解析/下载入口，无需为每个平台装不同工具。

## 二、核心优势

| 优势 | 说明 |
|---|---|
| **零运行时依赖（源码版）** | 后端仅用 Python 标准库 `http.server` + `yt-dlp`，不引入 Flask/Django 等框架；前端为原生 JS，无构建步骤 |
| **单文件 exe，双击即用** | PyInstaller 打包为 `VideoLinkCollector.exe`（约 446MB），内置 Python / yt-dlp / Playwright·Chromium / ffmpeg / VC++ 运行库，**无需目标机装任何环境** |
| **无水印下载** | 抖音直连优先无水印源 + 改写兜底；实测 100% 无水印（抽帧验证） |
| **双通道抗反爬** | HTTP 直连（B站 WBI 签名、微博游客握手）+ Playwright 真实浏览器拦截（抖音/小红书强反爬），连续空页计数 + 退避重试提升召回 |
| **服务端全量检索** | B站「作者+关键词」由官方接口做全量过滤，而非本地截断最新 150 条 |
| **本地优先、隐私友好** | 所有解析/下载在本地完成，Cookie 仅存于本机 `cookies/`，不上传 |
| **批量与播放列表** | 一键展开 B站歌单/合集、多选批量下载、结果导出 MD/CSV/TXT |

## 三、技术架构

```
video_link_collector/
├── app.py                 # 后端：HTTP 服务 + 路由 + 下载编排（约 4.9k 行）
├── collector_core.py      # 核心：各平台解析/检索逻辑（Bilibili/Kuaishou/Douyin…）（约 2.3k 行）
├── cookie_manager.py      # Cookie 加载/保存/Netscape 转换
├── collect_links.py       # 链接采集辅助
├── frontend/              # 原生 JS 前端（index.html / app.js / style.css）
├── cookies/               # 各平台登录态（douyin_cookies.txt 等 + profiles/）
└── downloads/             # 下载输出目录
```

**检索双通道**：
- HTTP 直连：`HttpClient`（自研 Cookie 管理）+ **WBI 签名**（`mixin_key` 重排 + MD5，纯标准库实现）绕过 B站反爬；微博先过 `visitor` 网关握手拿游客 Cookie。
- 浏览器通道：Playwright 驱动 Chromium 打开真实搜索页，拦截 XHR/fetch 响应提取直链，或滚屏抓 DOM。

## 四、具体使用步骤

### 方式 A：源码运行（开发 / 调试）

前置：本机已装 **Python 3.10+**（建议 3.11/3.12），并已 `pip install yt-dlp playwright` 后执行 `playwright install chromium`。

```bash
cd video_link_collector

# 或本机 Python
python app.py
```

启动后：
1. 自动监听 `http://127.0.0.1:8000/`（端口被占用自动顺延 8001…）。
2. 自动用默认浏览器打开页面（无 GUI 窗口，后台常驻服务）。
3. 在网页里粘贴链接使用。
4. **停止**：关闭浏览器标签页后，在启动它的终端按 `Ctrl+C`。（注意：改代码后必须杀掉旧进程重启，否则仍是内存里的旧代码。）

> 换端口：用环境变量 `PORT=8100 python app.py`。

### 方式 B：单文件 exe（分享 / 日常使用）

1. 将整个 `dist/` 文件夹发给对方（**必须连同 `cookies/` 一起**）。
2. 双击 `VideoLinkCollector.exe`：
   - 首次在临时目录解压内置组件（数秒到十几秒，请稍候）。
   - 自动打开浏览器访问 `http://127.0.0.1:8000/`。
3. 下载文件保存在 **exe 所在目录的 `downloads/`**（命名：`标题 - 作者[时长].mp4`）。
4. Cookie 保存在 **exe 所在目录的 `cookies/`**。

> 分享注意：`dist/` 需整体携带 `cookies/`，否则抖音解析拿不到登录态、作者名为空。

### 抖音下载前置（重要）

抖音核心走「浏览器直连」通道，**需先在网页「🔑 Cookie 管理」页登录抖音账号**，否则只能拿到元数据、无法下载视频。抖音有风控，偶发需重试。

## 五、各平台说明

| 平台 | 通道 | 登录需求 |

| 抖音 | 浏览器直连 | **需登录** |

## 六、常见问题 / 排错

- **抖音解析作者名为空 / handle**：未带 `cookies/` 或 Cookie 过期 → 重新在「Cookie 管理」登录抖音。
- **B站组合搜索召回少**：确认已勾选「使用已保存 Cookie」、网络未触发风控；代码已去除写死 150 条上限，由 `limit` 推导页数。
- **exe 启动慢 / 杀软误报**：单文件 exe 每次解压到临时目录属正常；体积大可能被误报，加白名单即可。
- **运行时不要移动 exe**：依赖临时解压目录，先关闭再移动。
- **改代码后下载仍是旧行为**：旧进程仍在内存运行，杀掉重启（源码版）或重新打包（exe 版）。
